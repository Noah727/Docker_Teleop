# Thesis Evaluation Raw Data

This root-level folder is for local raw materials collected for the thesis evaluation. It is intentionally ignored by Git in this checkout because it can contain videos, screenshots, logs, and rosbags.

Use one dated folder per collection session:

```text
thesis_eval_raw/MM_DD/
```

Do not edit raw files after collection unless you also document the change in that session's `notes.md`.

Use `complete_material/` for the curated subset that is ready to cite or convert into thesis tables and figures.
