# Backend Documentation

The active project documentation has been consolidated in the repository root `docs/` folder:

- `../../docs/System_Setup.md`: full replication/setup guide.
- `../../docs/Getting_Started.md`: daily bringup, controls, checkpoints, and recovery.
- `../../docs/Technical_Details.md`: architecture, networking, mapping, camera, recording, troubleshooting, and Git notes.

- `Task_Profile_Workflow.md`: how workspace, task group, and task object profiles are organized.

This folder is kept only as a pointer for older references.
